NutriApp KAlde

Mini-guideline desarrollado en Figma a partir de Atomic Design, trabajando una propuesta básica de sistema visual para una app ficticia de nutrición.

Contexto

Este proyecto consistió en construir un mini-guideline para una app ficticia llamada NutriApp KAlde, aplicando principios de Atomic Design en una propuesta básica de sistema visual.

El trabajo incluyó definición de paleta cromática, tipografía, componentes y una composición general que permitiera visualizar cómo se relacionan átomo, molécula y organismo dentro de una misma interfaz.

Enfoque

Más que desarrollar una app completa, el objetivo fue practicar cómo un sistema visual coherente puede construirse desde componentes pequeños, reutilizables y consistentes entre sí.

Atomic Design aplicado

La propuesta se organizó en tres niveles: un átomo para el input con estado focus, una molécula compuesta por formulario de acceso y botón principal, y un organismo representado por una pantalla de inicio de sesión completa.

Esta estructura permitió visualizar cómo los elementos pequeños pueden escalar a componentes más complejos sin perder coherencia visual ni funcional.

Video del prototipo

Además de la captura general, registré el proyecto en video para mostrar con más claridad la composición del mini-guideline y la forma en que se organizan los componentes dentro del archivo.

Esto permite observar mejor la relación entre las partes y cómo se presenta el sistema visual como conjunto.
