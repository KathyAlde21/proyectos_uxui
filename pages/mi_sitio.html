Mi Sitio

Sitio web responsive desarrollado en HTML, CSS y Bootstrap, luego replicado en Figma en versión escritorio y móvil, manteniendo el mismo concepto visual.

Contexto

Este proyecto fue desarrollado como un ejercicio práctico para trabajar la estructura base de una página web usando HTML, CSS y Bootstrap, con una propuesta visual simple y un personaje central que diera identidad al contenido.

Más adelante, la misma propuesta fue replicada en Figma en dos formatos, escritorio y móvil, manteniendo el mismo concepto visual para contrastar diseño y desarrollo.

Enfoque

A diferencia de los otros proyectos, aquí el foco no estuvo en una metodología UX/UI extensa, sino en construir una base responsive clara y luego trasladarla a Figma respetando la misma lógica visual.

Desarrollo responsive

La versión en código fue trabajada para adaptarse a distintos tamaños de pantalla, reorganizando bloques, imágenes y cards sin perder el concepto general del sitio.

Esto permitió pasar desde una disposición más amplia en escritorio a una lectura más vertical en móvil, manteniendo jerarquía, contenido y estilo visual.

Réplica en Figma

Después del desarrollo en código, el sitio fue replicado en Figma en versión escritorio y móvil, conservando el mismo concepto visual para observar cómo se traducía la propuesta entre ambas herramientas.

Esta parte del ejercicio fue útil para reforzar la relación entre maquetación, composición visual y adaptación responsive sin cambiar la idea original del proyecto.

Enlaces del proyecto

Como este proyecto no incluye documento ni video adicional, el cierre se apoya en sus dos salidas principales: la página publicada en GitHub Pages y el repositorio donde se encuentra el código.

Ambos enlaces permiten revisar la propuesta terminada y su implementación.
